# FinSentinel AI — 10-Day Build Plan

## Day 1 — Foundation (included in this scaffold)
- Monorepo and environment configuration
- FastAPI and Next.js application shells
- Docker Compose infrastructure
- Initial banking schemas
- Typed multi-agent contract
- CI and Kubernetes baselines

## Day 2 — Banking domain and persistence
- PostgreSQL migrations
- Customers, accounts, transactions, loans, cases, approvals, audit events
- Repository and service layers
- Seed data

## Day 3 — Machine-learning intelligence
- Fraud classifier
- Isolation Forest anomaly model
- Credit-risk classifier
- SHAP explanations
- MLflow tracking

## Day 4 — Qdrant, Neo4j, Redis, MinIO
- Policy ingestion and semantic retrieval
- Entity graph and suspicious-network queries
- Short-term memory and caching
- Document upload pipeline

## Day 5 — Dynamic LangGraph orchestration
- Supervisor and planner
- Parallel specialist agents
- Evidence aggregation
- Critic and decision gates
- Durable checkpoints and retries

## Day 6 — Fraud, AML, and credit workflows
- Complete investigation paths
- Contradiction detection
- Human approval and case replay

## Day 7 — Identity, authorization, and AI security
- Keycloak OAuth/OIDC
- JWT verification
- RBAC and OPA policies
- PII masking
- Prompt-injection and tool-permission controls

## Day 8 — Dynamic Next.js operations center
- Executive dashboard
- Live case stream
- Agent workflow animation
- Neo4j graph visualization
- Approval queue and audit viewer

## Day 9 — Production engineering
- OpenTelemetry
- Prometheus and Grafana dashboards
- Jaeger traces
- Kubernetes and Helm
- GitHub Actions security and deployment pipeline

## Day 10 — Integration and presentation
- End-to-end tests
- Load and adversarial tests
- Documentation and diagrams
- Demo scenarios, screenshots, resume bullets, and interview narrative
